# Simone Neuber – private Homepage

Diese Fassung basiert auf der inhaltlichen Masterfassung v21.1.

## Zum Anschauen

**`KONTROLLANSICHT.html`** ist die maßgebliche Vorschau. Sie enthält Gestaltung und Porträt vollständig in einer einzigen Datei und sieht daher auch lokal bzw. in einer Dateivorschau so aus wie die Masterfassung v21.1. An dieser Datei muss nichts gepflegt werden.

**`index.html`** ist die eigentliche Website-Datei für den Webspace. Sie verwendet `styles.css`, `app.js` und `assets/portrait.png`. Wird der gesamte Ordner gemeinsam auf einen Webspace geladen, ist ihre Darstellung dieselbe wie die Kontrollansicht. Einzelne Dateivorschauen können externe Ordnerbestandteile dagegen blockieren; dann sieht `index.html` vorübergehend unformatiert oder anders aus.

## Dateien

- `KONTROLLANSICHT.html` – selbständige Kontrollfassung, alles eingebettet
- `index.html` – Startseite der später veröffentlichten Website
- `styles.css` – Gestaltung, Mobilansicht und Druckregeln
- `app.js` – Navigation zwischen Forschung / Publikationen / Lehre / CV
- `assets/portrait.png` – Porträt

## Aktualisieren

Für die spätere Pflege sollst du weder Abstände noch Schriftgrößen anfassen müssen. Die jetzige technische Fassung ist bereits getrennt aufgebaut; als nächster Schritt kann die Inhalts-Pflege noch weiter vereinfacht werden, sodass Publikationen und Lehre nicht direkt im HTML bearbeitet werden müssen.

Bis dahin gilt: `styles.css` und `app.js` bleiben bei inhaltlichen Änderungen unangetastet.

## Veröffentlichung

Den **gesamten Ordner** unverändert auf einen Webspace hochladen. Als Startdatei dient `index.html`.
